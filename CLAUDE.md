# blow-up-my-social-media

Claude Code plugin. One front-door skill (`skills/blow-up-my-social-media`) plus `launch-pack`, `hand-raiser`, `comment-gate-loop`, and `platform-freshness-loop`. Shared knowledge lives in `references/` at the plugin root and is read by every skill via `../../references/`.

Rules for editing this repo:
- Platform files (`references/platforms/*.md`) carry a Verified date and [P]/[D]/[I] tags. Never add a platform claim without a dated source, and never upgrade a tag without one. Change the Verified date only after re-verifying.
- The plugin is brand-agnostic. No brand voice, palette, offers, or personal details in any file. Brand kits live outside the plugin.
- No promises of virality, reach, followers, or sales anywhere, including the README.
- The plugin drafts. Nothing in it may post, send, schedule, or connect an account without the user's explicit yes.
- Public author name is "Inspired Spitfire".
